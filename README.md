# WEB3ONE

واجهة تجريبية لتطبيق Web3 تجمع أقسامًا للمحفظة والأسواق وWeb3Market وWeb3Jobs والأخبار والطقس والترفيه والتواصل الاجتماعي.

> **حالة المشروع:** ما زال قيد التطوير. وجود واجهة أو تبويب لا يعني أن الخدمة الخلفية أو بياناتها الحية أو معاملات البلوكتشين مكتملة.

## ما يعمل حاليًا

- واجهة عربية/إنجليزية مع تصميم متجاوب.
- اتصال بمحفظة متوافقة مع EVM إذا كان مزوّد المحفظة متاحًا داخل المتصفح، مثل متصفح المحفظة أو إضافة متوافقة.
- قراءة عنوان الحساب والشبكة الحالية والرصيد الأصلي للشبكة عبر مزوّد المحفظة.
- تحديث حالة الحساب عند أحداث تغيير الحساب أو الشبكة.
- أقسام واجهة منفصلة للمحفظة والأسواق وWeb3Market وWeb3Jobs والتواصل الاجتماعي والأخبار والطقس والترفيه.

## ما لم يكتمل بعد

- **اختيار المحافظ عبر Reown AppKit / WalletConnect:** لم يتم دمج AppKit في هذا الفرع بعد؛ الاتصال الحالي يعتمد على window.ethereum.
- تحويلات إرسال فعلية، أو معاملات استلام/QR مكتملة، أو تبديل DEX.
- أرصدة رموز ERC-20 وأسعار السوق والقيمة الإجمالية بالدولار.
- دعم محافظ وسلاسل غير متوافقة مع EVM، أو تأكيد دعم عشر شبكات.
- لا تُدخل عبارة الاسترداد أو المفتاح الخاص في WEB3ONE. احتفظ بهما داخل تطبيق المحفظة الرسمي فقط.

أُوقفت الأزرار والإجراءات المالية غير المكتملة حتى لا توحي بنجاح معاملة لم تُنفّذ على البلوكتشين.

## التطوير المحلي

المشروع يستخدم React وVite وBun، ويحتوي على bun.lock. استخدم نسخة Bun المناسبة للمشروع، ثم:

```bash
bun install --frozen-lockfile
bun run dev
```

لبناء نسخة الإنتاج:

```bash
bun run build
```

ولفحص TypeScript:

```bash
bun run lint
```

افتح عنوان التطوير الذي يطبعه Vite في الطرفية (الإعداد الحالي يستخدم المنفذ 3000).

## العمل بأمان

- يجري التطوير على فرع feat/real-wallet-connect.
- لا تُدمج التغييرات إلى main قبل المراجعة والموافقة.
- عند إضافة مكتبات جديدة، حدّث package.json وbun.lock معًا، وتأكد من نجاح البناء باستخدام --frozen-lockfile.
